# 第二十三批识字卡：第023组「更多家庭成员」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0440 的单卡、已有打印页、PDF，以及第001组到第022组的说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：023
- 主题：更多家庭成员
- 卡号：H0441–H0460

字表没有定稿例句。例句按第001组的难度起草，例词用字表候选。

多音字按例词取音：

- 亲：父亲，取 qīn，不用 qìng。
- 戚：亲戚，取 qī，不用 cù。亲戚的「戚」读轻声。
- 伯：叔伯，取 bó，不用 bǎi、mò、bà。
- 祖：祖国，取 zǔ，不用 jiē。
- 兄：兄弟，取 xiōng，不用 kuàng。
- 夫：夫人，取 fū，不用 fú。
- 妻：妻子，取 qī，不用 qì。妻子的「子」读轻声。
- 姓：百姓，取 xìng，不用 shēng。
- 名：著名，取 míng，不用 mìng。

叔叔的后一个「叔」、姑娘的「娘」、舅舅的后一个「舅」、老婆的「婆」、嫂子的「子」、媳妇的「妇」、丈夫的「夫」读轻声。
