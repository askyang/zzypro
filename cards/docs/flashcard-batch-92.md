# 第九十二批识字卡：第092组「贝、赤、走部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1820 的单卡、已有打印页、PDF，以及第001组到第091组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、党参、凯风、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难、矛盾，以及已经用姓氏的卡，都留着。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：092
- 主题：贝、赤、走部字形联系
- 卡号：H1821–H1840

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。实在没有生活词，才用姓氏。

多音字按例词取音：

- 贾：姓贾，取 jiǎ，不用 gǔ。
- 赫：姓赫，取 hè，不用 shì。

财、贡、质、贫、贯、贤、费、贸、贷、资、贼、赏、赋、赖、赞、赤、赵、赴在这一组的例词里只有一个读音，分别是 cái、gòng、zhì、pín、guàn、xián、fèi、mào、dài、zī、zéi、shǎng、fù、lài、zàn、chì、zhào、fù。

## 改掉的候选

- H1821 财：字表候选是「财产」，偏成人。改用「发财树」，读 fā cái shù。花盆上没有字。

- H1831 贼：字表候选是「流贼」，不适合儿童。同字没有儿童生活词，改用「姓贼」，读 xìng zéi。画面只是站着的孩子。

- H1833 赏：字表候选是「欣赏」，偏抽象。改用「赏花」，读 shǎng huā。
- H1834 赋：字表候选是「赋予」，偏书面。同字没有儿童生活词，改用「姓赋」，读 xìng fù。
- H1835 赖：字表候选是「依赖」，偏抽象。改用「耍赖」，读 shuǎ lài。
- H1836 赞：字表候选是「赞成」，偏抽象。改用「赞美」，读 zàn měi。纸上只有小猫，没有字。
- H1837 赤：字表候选是「赤壁」，是历史地名。改用「赤脚」，读 chì jiǎo。
- H1838 赫：字表候选是「显赫」，偏成人。同字没有儿童生活词，改用「姓赫」，读 xìng hè。
- H1839 赵：字表候选是「后赵」，是历史国名。赵常用作姓，改用「姓赵」，读 xìng zhào。
- H1840 赴：字表候选是「奔赴」，偏书面。同字没有儿童生活词，改用「姓赴」，读 xìng fù。
