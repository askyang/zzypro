# 第五十五批识字卡：第055组「人部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1080 的单卡、已有打印页、PDF，以及第001组到第054组的说明都没有改。H0485 也没有改。H0981「的」和 H0982「了」的读音留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：055
- 主题：人部字形联系
- 卡号：H1081–H1100

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 侵：侵晨，取 qīn，不用 qǐn。
- 促：促进，取 cù，不用 chuò。
- 俊：俊美，取 jùn，不用 shùn、dūn。
- 侯：公侯，取 hóu，不用 hòu。
- 候：时候，取 hòu。候读轻声 hou。
- 倒：绊倒，取 dǎo，不用 dào。字表字头写的是 dào，例词「绊倒」不取这个音。
- 倘：倘佯，取 cháng，不用 tǎng。字表字头写的是 tǎng，例词「倘佯」不取这个音。
- 俱：俱乐部，取 jù，不用 jū。乐读 lè。
- 假：假定，取 jiǎ，不用 jià、jie、xià、xiá、gé。

保、修、俄、俗、值、倾、债、做、偏、偷、偶在这一组的例词里只有一个读音，分别是 bǎo、xiū、é、sú、zhí、qīng、zhài、zuò、piān、tōu、ǒu。

## 改掉的候选

- H1083 俄：字表候选是「俄方」，不适合儿童。改用「俄语」，读 é yǔ。
- H1084 侵：字表候选是「侵略」，不适合儿童。改用「侵晨」，读 qīn chén。
- H1091 倒：字表候选是「打倒」，不适合儿童。改用「绊倒」，读 bàn dǎo。

偷偷画的是从树后看一看，没有偷东西。绊倒画的是脚绊到树根，没有受伤。
