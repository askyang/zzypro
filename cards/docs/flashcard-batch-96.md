# 第九十六批识字卡：第096组「门、阜部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1900 的单卡、已有打印页、PDF，以及第001组到第095组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、党参、凯风、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难、矛盾，以及已经用姓氏的卡，都留着。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：096
- 主题：门、阜部字形联系
- 卡号：H1901–H1920

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。实在没有生活词，才用姓氏。

多音字按例词取音：

- 邓：姓邓，取 dèng，不用 shān。
- 陆：陆地，取 lù，不用 liù。
- 阿：阿姨，取 ā，不用 ē、ě、ǎ、à、a。
- 附：附近，取 fù，不用 bù、fū。
- 阻：阻止，取 zǔ，不用 zhù。

热闹里，闹读轻声 nao。闲着的着读轻声 zhe。一阵里，一在第四声「阵」前读 yí。阵本身读 zhèn。

闭、闯、闻、阁、阔、队、阳、阶、邦、际、陈、邻在这一组的例词里只有一个读音，分别是 bì、chuǎng、wén、gé、kuò、duì、yáng、jiē、bāng、jì、chén、lín。

## 改掉的候选

- H1901 闭：字表候选是「闭会」，偏成人。改用「闭上」，读 bì shàng。
- H1903 闲：字表候选是「休闲」，偏成人。改用「闲着」，读 xián zhe。
- H1905 闻：字表候选是「新闻」，偏成人。改用「闻花」，读 wén huā。
- H1906 阁：字表候选是「内阁」，偏政治。改用「阁楼」，读 gé lóu。窗户上没有字。
- H1907 阔：字表候选是「广阔」，偏书面。改用「宽阔」，读 kuān kuò。路上没有牌子。
- H1908 队：字表候选是「部队」，不适合儿童。改用「排队」，读 pái duì。
- H1909 邓：字表候选是「邓昌伶」，是人名。邓常用作姓，改用「姓邓」，读 xìng dèng。
- H1910 阳：字表候选是「当阳」，是地名。改用「太阳」，读 tài yáng。
- H1911 阶：字表候选是「阶段」，偏抽象。改用「台阶」，读 tái jiē。门上没有字。
- H1912 邦：字表候选是「城邦」，偏历史。同字没有儿童生活词，改用「姓邦」，读 xìng bāng。
- H1914 际：字表候选是「国际」，偏成人。同字没有儿童生活词，改用「姓际」，读 xìng jì。
- H1915 陆：字表候选是「大陆」，偏地理。改用「陆地」，读 lù dì。没有地图。
- H1916 陈：字表候选是「条陈」，偏书面。陈常用作姓，同字没有儿童生活词，改用「姓陈」，读 xìng chén。
- H1917 阿：字表候选是「阿訇」，不适合儿童。改用「阿姨」，读 ā yí。
- H1920 邻：字表候选是「邻近」，偏书面。改用「邻居」，读 lín jū。门上没有字。
