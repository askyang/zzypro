# 第六十二批识字卡：第062组「土、士、夂等部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1220 的单卡、已有打印页、PDF，以及第001组到第061组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：062
- 主题：土、士、夂等部字形联系
- 卡号：H1221–H1240

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。

多音字按例词取音：

- 堆：一堆，取 duī，不用 zuī。堆是第一声，所以「一」读 yì。
- 塔：宝塔，取 tǎ，不用 dā、da。
- 堡：城堡，取 bǎo，不用 bǔ、pù。
- 塞：塞住，取 sāi，不用 sài、sè。
- 填：填满，取 tián，不用 tiǎn、chén、zhèn。
- 增：增长，取 zēng，不用 zèng、céng。
- 壳：贝壳，取 ké，不用 qiào。
- 处：到处，取 chù，不用 chǔ。
- 太：太阳，取 tài，不用 tā。
- 失：失败，取 shī，不用 yì。
- 央：中央，取 yāng，不用 yīng。

堂、堰、墓、境、壮、备、复、够、夺在这一组的例词里只有一个读音，分别是 táng、yàn、mù、jìng、zhuàng、bèi、fù、gòu、duó。

## 改掉的候选

- H1221 堂：字表候选是「教堂」，偏成人场所。改用「课堂」，读 kè táng。
- H1223 塔：字表候选是「炮塔」，是武器。改用「宝塔」，读 bǎo tǎ。
- H1225 堡：字表候选是「堡垒」，偏军事。改用「城堡」，读 chéng bǎo。
- H1227 塞：字表候选是「活塞」，偏机械。改用「塞住」，读 sāi zhù。不用「边塞」。
- H1228 填：字表候选是「填报」，偏成人。改用「填满」，读 tián mǎn。
- H1232 壳：字表候选是「地壳」，壳在这里读 qiào。改用「贝壳」，读 bèi ké。
- H1233 处：字表候选是「处理」，读 chǔ，偏成人。改用「到处」，读 dào chù。
- H1235 复：字表候选是「恢复」，偏书面。改用「复习」，读 fù xí。
- H1237 太：字表候选是「太监」，不适合儿童。改用「太阳」，读 tài yáng。
- H1240 夺：字表候选是「夺取」，偏成人。改用「夺过」，读 duó guò。
