# 第四十五批识字卡：第045组「发现与比较」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0880 的单卡、已有打印页、PDF，以及第001组到第044组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。算有 14 笔，格子收在卡片里。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：045
- 主题：发现与比较
- 卡号：H0881–H0900

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 观：观点，取 guān，不用 guàn。
- 探：探索，取 tàn，不用 xián。
- 研：研究，取 yán，不用 yàn、xíng。
- 究：研究，取 jiū，不用 jiù。
- 化：文化，取 huà，不用 huā、huò。
- 比：比较，取 bǐ，不用 bì、pí、pǐ。
- 量：大量，取 liàng，不用 liáng。若要「测量」的 liáng，例词不能再用「大量」。这一组测的例词仍是「测量」，量在那个词里读 liáng，但量这张卡用的是「大量」。
- 估：估计，取 gū，不用 gù。
- 差：差别，取 chā，不用 chà、chāi、cī。字表字头写的是 chà，例词「差别」不取这个音。
- 倍：一倍，取 bèi，不用 péi。一读 yí。
- 于：位于，取 yú，不用 wéi、yū、xū。

探和索都用「探索」。研和究都用「研究」。

## 改掉的候选

- H0897 总：字表候选是「总理」，不适合儿童。改用「总共」，读 zǒng gòng。

总共画的是五个苹果，图上没有数字。测量的尺子上没有刻度数字。
