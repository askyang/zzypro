# 第五十批识字卡：第050组「表达与连接」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0980 的单卡、已有打印页、PDF，以及第001组到第049组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：050
- 主题：表达与连接
- 卡号：H0981–H1000

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 的：目的，取 dì，不用 de、dí。字表字头写的是 de，例词「目的」不取这个音。若要「我的」的 de，例词不能再用「目的」。
- 了：了解，取 liǎo，不用 le、liào。字表字头写的是 le，例词「了解」不取这个音。
- 吗：好吗，取轻声 ma，不用 má、mǎ。
- 呢：你呢，取轻声 ne，不用 ní。
- 吧：好吧，取轻声 ba，不用 bā。
- 啊：啊呀呀，取 ā。
- 呀：啊呀呀，取 yā，不用轻声 ya、xiā。啊和呀都用「啊呀呀」。
- 哦：吟哦，取 é，不用 ó、ò。字表字头写的是 ó，例词「吟哦」不取这个音。
- 这：这个，取 zhè，不用 zhèi。个读轻声 ge。
- 那：那么，取 nà。么读轻声 me。
- 哪：哪里，取 nǎ，不用 na。
- 各：各种，取 gè，不用 gě。
- 某：某些，取 mǒu，不用 méi。
- 别：特别，取 bié，不用 biè。
- 也：也许，取 yě，不用 yí。
- 和：和谐，取 hé，不用 hè、huó、huo。

## 改掉的候选

- H0983 吗：字表候选是「干吗」，不适合儿童。改用「好吗」，读 hǎo ma。
- H0984 呢：字表候选是「呢绒」，不适合儿童。改用「你呢」，读 nǐ ne。
- H0985 吧：字表候选是「网吧」，不适合儿童。改用「好吧」，读 hǎo ba。

目的画的是伸手拿苹果，没有箭。吟哦没有书。
