# 第三十一批识字卡：第031组「地理与风景」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0600 的单卡、已有打印页、PDF，以及第001组到第030组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：031
- 主题：地理与风景
- 卡号：H0601–H0620

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 地：地方，取 dì，不用 de。地方的「方」读轻声。
- 溪：溪水，取 xī，不用 qī。
- 池：电池，取 chí，不用 tuó、chè。
- 洋：洋芋，取 yáng，不用 xiáng、yǎng。
- 沙：沙漠，取 shā，不用 shà、suō。
- 岭：岭子，取 lǐng，不用 líng。岭子的「子」读轻声。

## 改掉的候选

- H0602 海：字表候选是「海军」，和军队有关，不适合儿童。改用「大海」，读 dà hǎi。
