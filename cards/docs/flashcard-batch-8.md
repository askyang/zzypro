# 第八批识字卡：第008组「吃饭与味道」

版式与第002组相同：笔顺写在红色方格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的卡片、打印页、PDF 和说明都没有改。

例词用字表候选。例句按生活场景起草，可以改。

## 这一组

- 阶段：生活启蒙
- 组号：008
- 主题：吃饭与味道
- 卡号：H0141–H0160

喝用 hē，不用 hè、yè。包用 bāo（面包），不用 páo。汤用 tāng。油用 yóu。勺用 sháo。

杯子的「子」读轻声 zi。
