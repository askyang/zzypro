# 第三十八批识字卡：第038组「服饰与材料」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0740 的单卡、已有打印页、PDF，以及第001组到第037组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：038
- 主题：服饰与材料
- 卡号：H0741–H0760

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 服：服务，取 fú，不用 fù、bì、bó。
- 袍：龙袍，取 páo，不用 bào。
- 缝：缝隙，取 fèng，不用 féng。若要「缝纫」的 féng，例词不能再用「缝隙」。

袖子的「子」、兜里的「里」读轻声。

## 改掉的候选

- H0743 袖：字表候选是「领袖」，不适合儿童。改用「袖子」，读 xiù zi。
- H0745 扣：字表候选是「回扣」，不适合儿童。改用「纽扣」，读 niǔ kòu。
- H0758 针：字表候选是「方针」，不适合儿童。改用「针线」，读 zhēn xiàn。
- H0760 裁：字表候选是「总裁」，不适合儿童。改用「裁衣」，读 cái yī。
