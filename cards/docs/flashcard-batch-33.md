# 第三十三批识字卡：第033组「交通工具」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0640 的单卡、已有打印页、PDF，以及第001组到第032组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：033
- 主题：交通工具
- 卡号：H0641–H0660

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 汽：汽车，取 qì，不用 gài、yǐ。
- 列：列为，取 liè，不用 lì。
- 客：游客，取 kè，不用 qià。
- 乘：乘机，取 chéng，不用 shèng。
- 帆：帆船，取 fān，不用 fán、fàn。

## 改掉的候选

- H0643 胎：字表候选是「胎儿」，不适合儿童。改用「轮胎」，读 lún tāi。
- H0652 舵：字表候选是「舵主」，不适合儿童。改用「舵轮」，读 duò lún。
- H0654 艇：字表候选是「潜艇」，是军事词。改用「小艇」，读 xiǎo tǐng。
- H0655 舰：字表候选是「舰队」，是军事词。改用「舰船」，读 jiàn chuán。
