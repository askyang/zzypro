# 第五十四批识字卡：第054组「人部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1060 的单卡、已有打印页、PDF，以及第001组到第053组的说明都没有改。H0485 也没有改。H0981「的」和 H0982「了」的读音留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：054
- 主题：人部字形联系
- 卡号：H1061–H1080

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 休：休息，取 xiū，不用 xù。息读轻声 xi。
- 伏：起伏，取 fú，不用 fù。
- 仰：信仰，取 yǎng，不用 áng。
- 仿：仿佛，取 fǎng，不用 páng。佛读 fú。
- 但：但愿，取 dàn，不用 tǎn、yàn。
- 位：单位，取 wèi，不用 lì。
- 何：如何，取 hé，不用 hè。
- 余：其余，取 yú，不用 tú、xú、yù。
- 佛：仿佛，取 fú，不用 fó、bó、bì。仿读 fǎng。仿和佛都用「仿佛」。
- 供：提供，取 gōng，不用 gòng。
- 依：依然，取 yī，不用 yǐ。
- 例：例如，取 lì，不用 liè。

伦、伍、伟、伐、住、使、佳、侍在这一组的例词里只有一个读音，分别是 lún、wǔ、wěi、fá、zhù、shǐ、jiā、shì。

## 改掉的候选

这一组没有改字表候选。队伍画的是小朋友排队拿苹果，没有军人。
