# 第十四批识字卡：第014组「时间与生活」

版式与第002组相同，组词粗体放大，例句在插画正下方并粗体放大。从这一组第一张卡起，笔顺改用红色田字格。

前面各组的卡片、打印页、PDF 和说明都没有改。H0001–H0260 仍是原来的红色方格笔顺。

## 笔顺田字格

从 **H0261** 起，每一笔写在红色田字格里。格有红色外框，还有红色虚线中心十字（横中线、竖中线），和左侧大字的田字格是同一套。已经写过的笔画是深灰色，当前这一笔是橙红色，笔画都落在格内。

## 这一组

- 阶段：生活启蒙
- 组号：014
- 主题：时间与生活
- 卡号：H0261–H0280

多音字按例词取音：

- 明：明天，取 míng，不用 mèng。
- 年：新年，取 nián，不用 nìng。
- 春：春天，取 chūn，不用 chǔn。
- 夏：夏天，取 xià，不用 jiǎ。
- 分：分钟，取 fēn，不用 fèn、fén。
- 醒：醒来，取 xǐng，不用 chéng、jīng。

早上、晚上的「上」读轻声 shang。醒来的「来」读轻声 lai。一秒的「一」按在第三声前变调，读 yì miǎo。
