# 第二十二批识字卡：第022组「卫生与习惯」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0420 的单卡、已有打印页、PDF，以及第001组到第021组的说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：022
- 主题：卫生与习惯
- 卡号：H0421–H0440

字表没有定稿例句。例句按第001组的难度起草，例词用字表候选。

多音字按例词取音：

- 澡：洗澡，取 zǎo，不用 cāo。
- 肥：化肥，取 féi，不用 bǐ。
- 膏：石膏，取 gāo，不用 gào。
- 洁：清洁，取 jié，不用 jí。
- 清：清楚，取 qīng，不用 qìng。清楚的「楚」读轻声。
- 扫：扫描，取 sǎo，不用 sào。若要「扫帚」的 sào，例词不能再用「扫描」。
- 拖：拖延，取 tuō，不用 chǐ。
- 抹：一抹，取 mǒ，不用 mā、mò。一抹的「一」在第三声前读 yì。
- 垃：垃圾，取 lā，不用轻声 la。
- 圾：垃圾，取 jī，不用 jí、jié。
- 齐：一齐，取 qí，不用 jì。一齐的「一」在第二声前读 yì。
- 勤：后勤，取 qín，不用 qí。
