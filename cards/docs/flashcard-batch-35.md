# 第三十五批识字卡：第035组「城市与公共场所」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0680 的单卡、已有打印页、PDF，以及第001组到第034组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：035
- 主题：城市与公共场所
- 卡号：H0681–H0700

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 市：市场，取 shì，不用 fú。
- 区：地区，取 qū，不用 ōu。
- 都：字表参考音是 dōu。例词「首都」读 dū，卡上写 dū，不用 dōu。若要「都是」的 dōu，例词不能再用「首都」。
- 巷：街巷，取 xiàng，不用 hàng。
- 广：广泛，取 guǎng，不用 yǎn、ān。
- 铺：店铺，取 pù，不用 pū。若要「铺床」的 pū，例词不能再用「店铺」。

## 改掉的候选

- H0684 镇：字表候选是「镇压」，不适合儿童。改用「小镇」，读 xiǎo zhèn。
