# 第六批识字卡：第006组「身边的动物」

版式与第002组相同：笔顺写在红色方格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的卡片、打印页、PDF 和说明都没有改。

例词用字表候选。例句按生活场景起草，可以改。

## 这一组

- 阶段：生活启蒙
- 组号：006
- 主题：身边的动物
- 卡号：H0101–H0120

猫用 māo，不用 miáo、máo。兔用 tù。虎用 hǔ，不用 hù。鸟用 niǎo。虫用 chóng，不用 huǐ。蚂用 mǎ（蚂蚁），不用 mà、mā。

兔子、猴子、鸭子的「子」读轻声 zi。
