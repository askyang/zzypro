# 第九十批识字卡：第090组「虫、血、行等部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1780 的单卡、已有打印页、PDF，以及第001组到第089组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、党参、凯风、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难、矛盾，以及已经用姓氏的卡，都留着。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：090
- 主题：虫、血、行等部字形联系
- 卡号：H1781–H1800

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。实在没有生活词，才用姓氏。

多音字按例词取音：

- 血：姓血，取 xuè，不用 xiě。
- 衰：姓衰，取 shuāi，不用 suō、cuī。
- 裂：裂开，取 liè，不用 liě。
- 见：看见，取 jiàn，不用 xiàn。
- 觉：觉得，取 jué，不用 jiào。得读轻声 de。
- 解：解开，取 jiě，不用 jiè、xiè。
- 许：许多，取 xǔ，不用 hǔ。

融、衡、表、袁、袭、览、触、订、议、让、训、讯、设在这一组的例词里只有一个读音，分别是 róng、héng、biǎo、yuán、xí、lǎn、chù、dìng、yì、ràng、xùn、xùn、shè。

## 改掉的候选

- H1781 融：字表候选是「金融」，偏成人。改用「融化」，读 róng huà。
- H1782 血：字表候选是「血液」。同字没有不靠血液的儿童生活词，改用「姓血」，读 xìng xuè。画面是站着的孩子，不画血。
- H1784 表：字表候选是「代表」，偏抽象。改用「表弟」，读 biǎo dì。
- H1785 袁：字表候选是「袁枢」，是人名。同字没有儿童生活词，改用「姓袁」，读 xìng yuán。
- H1786 衰：字表候选是「衰落」，偏书面。同字没有儿童生活词，改用「姓衰」，读 xìng shuāi。
- H1787 袭：字表候选是「袭击」，不适合儿童。同字没有儿童生活词，改用「姓袭」，读 xìng xí。
- H1788 裂：字表候选是「分裂」，偏抽象。改用「裂开」，读 liè kāi。画面是裂开的饼干。
- H1789 见：字表候选是「意见」，偏抽象。改用「看见」，读 kàn jiàn。
- H1791 览：字表候选是「概览」，偏书面。改用「游览」，读 yóu lǎn。公园里没有牌子。
- H1792 解：字表候选是「解决」，偏抽象。改用「解开」，读 jiě kāi。画面是解开礼物上的蝴蝶结。
- H1793 触：字表候选是「接触」，偏抽象。改用「触摸」，读 chù mō。
- H1794 订：字表候选是「签订」，偏成人。改用「订正」，读 dìng zhèng。纸是空白的，没有字。
- H1795 议：字表候选是「会议」，偏成人。同字没有儿童生活词，改用「姓议」，读 xìng yì。
- H1796 让：字表候选是「不让」，意思偏否定。改用「让座」，读 ràng zuò。
- H1798 讯：字表候选是「资讯」，偏成人。同字没有儿童生活词，改用「姓讯」，读 xìng xùn。
- H1799 设：字表候选是「建设」，偏成人。改用「设计」，读 shè jì。画面是孩子画房子，纸上没有字。
