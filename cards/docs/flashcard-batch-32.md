# 第三十二批识字卡：第032组「观察天气」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0620 的单卡、已有打印页、PDF，以及第001组到第031组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。露有 21 笔，田字格略缩小，使每一笔都留在卡片里面。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：032
- 主题：观察天气
- 卡号：H0621–H0640

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 露：字表参考音是 lù。例词「露出」读 lòu，卡上写 lòu，不用 lù。若要「露水」的 lù，例词不能再用「露出」。
- 虹：虹膜，取 hóng，不用 jiàng、hòng、gòng。
- 震：地震，取 zhèn，不用 shēn。
- 温：温度，取 wēn，不用 yùn。
- 凉：荒凉，取 liáng，不用 liàng。

## 改掉的候选

- H0622 阴：字表候选是「阴谋」，不适合儿童。改用「阴天」，读 yīn tiān。
