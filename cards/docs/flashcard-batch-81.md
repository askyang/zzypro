# 第八十一批识字卡：第081组「火、父、片等部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1600 的单卡、已有打印页、PDF，以及第001组到第080组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：081
- 主题：火、父、片等部字形联系
- 卡号：H1601–H1620

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。

多音字按例词取音：

- 炎：炎热，取 yán，不用 yàn、tán。
- 烦：麻烦，取轻声 fan，组词读 má fan。
- 焦：焦急，取 jiāo，不用 qiáo。
- 熙：姓熙，取 xī，不用 yí。
- 熟：熟了，取 shú，不用 shóu。了读轻声 le。
- 燃：燃着，取 rán。着读轻声 zhe。
- 爹：爹爹，读 diē die。后一个爹读轻声。
- 片：一片，取 piàn，不用 piān、pàn。一在第四声前读 yí。
- 狂：狂风，取 kuáng，不用 jué。

灰、灵、灾、炼、烈、然、照、煤、版、牵、犯在这一组的例词里只有一个读音，分别是 huī、líng、zāi、liàn、liè、rán、zhào、méi、bǎn、qiān、fàn。

## 改掉的候选

- H1602 灵：字表候选是「灵魂」，偏成人。改用「灵活」，读 líng huó。画面是跳起来的小猫。
- H1609 焦：字表候选是「焦点」，偏抽象。改用「焦急」，读 jiāo jí。画面是在窗口等的孩子，没有钟。
- H1612 熙：字表候选是「光熙」，孩子不常见。改用「姓熙」，读 xìng xī。
- H1613 熟：字表候选是「成熟」，偏抽象。改用「熟了」，读 shú le。
- H1614 燃：字表候选是「燃烧」，火势太大。改用「燃着」，读 rán zhe。画面是一支小蜡烛。
- H1617 版：字表候选是「出版」，偏成人。改用「版画」，读 bǎn huà。画面是一条鱼的印画，没有字。
- H1618 牵：字表候选是「牵引」，偏机械。改用「牵手」，读 qiān shǒu。
- H1619 犯：字表候选是「犯罪」，不适合儿童。改用「犯困」，读 fàn kùn。
- H1620 狂：字表候选是「疯狂」，不适合儿童。改用「狂风」，读 kuáng fēng。画面是被风吹弯的草和树。
