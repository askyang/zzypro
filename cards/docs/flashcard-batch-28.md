# 第二十八批识字卡：第028组「森林里的动物」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0540 的单卡、已有打印页、PDF，以及第001组到第027组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：028
- 主题：森林里的动物
- 卡号：H0541–H0560

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 狼：狼狈，取 láng，不用 lǎng、làng、hǎng。
- 鹿：麋鹿，取 lù，不用 lǘ。
- 野：野生，取 yě，不用 shù。
- 蹄：马蹄，取 tí，不用 dì。
- 爪：字表参考音是 zhǎo。例词「爪子」读 zhuǎ，卡上写 zhuǎ。爪子的「子」读轻声。若要 zhǎo，例词不能再用「爪子」。
- 角：角度，取 jiǎo，不用 jué、lù、gǔ。
- 纹：纹饰，取 wén，不用 wèn。

狮子、豹子、狐狸、刺猬、爪子的后一个字读轻声。猩猩的后一个「猩」读轻声。猛地的「地」读轻声。

## 改掉的候选

这一组没有改。字表候选都不属于毒品、武器、血腥、成人用语或疾病名。
