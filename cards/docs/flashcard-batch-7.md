# 第七批识字卡：第007组「水果和蔬菜」

版式与第002组相同：笔顺写在红色方格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的卡片、打印页、PDF 和说明都没有改。

例词用字表候选。例句按生活场景起草，可以改。

## 这一组

- 阶段：生活启蒙
- 组号：007
- 主题：水果和蔬菜
- 卡号：H0121–H0140

茄的字表参考音是 jiā，例词「茄子」读 qié zi，这张卡用 qié。桃用 táo。蕉用 jiāo。葡用 pú。葱用 cōng。

梨子、桃子、杏子、李子、橘子、豆子、茄子的「子」读轻声 zi。萄单字用 táo，葡萄里读轻声 tao。菇单字用 gū，蘑菇里读轻声 gu。
