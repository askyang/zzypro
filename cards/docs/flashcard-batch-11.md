# 第十一批识字卡：第011组「出门与交通」

版式与第002组相同：笔顺写在红色方格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的卡片、打印页、PDF 和说明都没有改。

例词用字表候选。例句按生活场景起草，可以改。

## 这一组

- 阶段：生活启蒙
- 组号：011
- 主题：出门与交通
- 卡号：H0201–H0220

多音字按例词取音：

- 车：汽车，取 chē，不用 jū。
- 机：飞机，取 jī，不用 wèi。
- 路：马路，取 lù，不用 luò。
- 站：车站，取 zhàn，不用 zhān。
- 园：公园，取 yuán，不用 wán。
- 校：学校，取 xiào，不用 jiào、jiǎo、qiāo。
- 房：房子，取 fáng，不用 páng。
- 过：过桥，取 guò，不用 guō。
- 来：单字用 lái。过来里的「来」读轻声 lai。
- 去：单字用 qù，不用 qū。回去里的「去」读轻声 qu。

院子、房子的「子」读轻声 zi。
