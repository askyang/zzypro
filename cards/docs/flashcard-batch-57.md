# 第五十七批识字卡：第057组「几、凵、刀部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1120 的单卡、已有打印页、PDF，以及第001组到第056组的说明都没有改。H0485 也没有改。H0981「的」、H0982「了」和 H1084「侵晨」留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：057
- 主题：几、凵、刀部字形联系
- 卡号：H1121–H1140

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 划：计划，取 huà，不用 huá、guò、guǒ、huai。
- 创：创造，取 chuàng，不用 chuāng。
- 免：免费，取 miǎn，不用 wèn、wǎn。
- 刺：刺激，取 cì，不用 cī、qì。
- 券：入场券，取 quàn，不用 xuàn。
- 削：削苹果，取 xiāo，不用 xuē、qiào、shào。字表字头写的是 xuē，例词「削苹果」不取这个音。

凤、凭、凯、凶、击、争、刘、刚、刑、利、到、制、剂、剑在这一组的例词里只有一个读音，分别是 fèng、píng、kǎi、xiōng、jī、zhēng、liú、gāng、xíng、lì、dào、zhì、jì、jiàn。

## 改掉的候选

- H1123 凯：字表候选是「奏凯」，不适合儿童。改用「凯风」，读 kǎi fēng。
- H1125 击：字表候选是「攻击」，不适合儿童。改用「击掌」，读 jī zhǎng。
- H1126 争：字表候选是「战争」，不适合儿童。改用「争先」，读 zhēng xiān。
- H1129 刘：字表候选是「刘澜涛」，不适合儿童。改用「姓刘」，读 xìng liú。
- H1131 刑：字表候选是「刑部」，不适合儿童。改用「姓刑」，读 xìng xíng。
- H1133 免：字表候选是「任免」，不适合儿童。改用「免费」，读 miǎn fèi。
- H1138 券：字表候选是「证券」，不适合儿童。改用「入场券」，读 rù chǎng quàn。
- H1139 剑：字表候选是「长剑」，不适合儿童。改用「剑兰」，读 jiàn lán。
- H1140 削：字表候选是「剥削」，不适合儿童。改用「削苹果」，读 xiāo píng guǒ。

刺激画的是一只柠檬，没有刀。剑兰是花。削苹果只画了果皮，没有刀。
