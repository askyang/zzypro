# 第五十三批识字卡：第053组「人部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1040 的单卡、已有打印页、PDF，以及第001组到第052组的说明都没有改。H0485 也没有改。H0981「的」和 H0982「了」的读音留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：053
- 主题：人部字形联系
- 卡号：H1041–H1060

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 从：从事，取 cóng，不用 zòng。
- 仅：仅仅，取 jǐn，不用 fù、nú、jìn。
- 介：介绍，取 jiè，不用 gè。
- 仇：姓仇，取 qiú，不用 chóu、jū。字表字头写的是 chóu，例词「姓仇」不取这个音。
- 令：命令，取 lìng，不用 líng、lǐng、lián。
- 仙：仙桃，取 xiān，不用 xiǎn。
- 任：任务，取 rèn，不用 rén、lìn。务读轻声 wu。
- 件：条件，取 jiàn，不用 móu。
- 传：传统，取 chuán，不用 zhuàn。
- 众：群众，取 zhòng，不用 yín。
- 似：似乎，取 sì，不用 shì。字表字头写的是 shì，例词「似乎」不取这个音。
- 优：优势，取 yōu，不用 yóu。
- 份：股份，取 fèn，不用 bīn。

仍、仁、代、仪、仗、企、伊在这一组的例词里只有一个读音，分别是 réng、rén、dài、yí、zhàng、qǐ、yī。

## 改掉的候选

- H1046 仇：字表候选是「报仇」，不适合儿童。改用「姓仇」，读 xìng qiú。
- H1051 仗：字表候选是「打仗」，不适合儿童。改用「依仗」，读 yī zhàng。
- H1060 伊：字表候选是「两伊」，不适合儿童。改用「伊始」，读 yī shǐ。

命令画的是收拾积木，没有军人。
