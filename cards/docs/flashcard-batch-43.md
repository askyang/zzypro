# 第四十三批识字卡：第043组「音乐与表演」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0840 的单卡、已有打印页、PDF，以及第001组到第042组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。蹈有 17 笔，格子收在卡片里。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：043
- 主题：音乐与表演
- 卡号：H0841–H0860

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 声：一声，取 shēng，不用 qìng。一读 yì。
- 弹：弹琴，取 tán，不用 dàn。若要「子弹」的 dàn，例词不能再用「弹琴」。
- 奏：节奏，取 zòu，不用 còu。
- 打：打鼓，取 dǎ，不用 dá。
- 曲：曲折，取 qū，不用 qǔ。若要「歌曲」的 qǔ，例词不能再用「曲折」。
- 戏：游戏，取 xì，不用 hū。
- 台：平台，取 tái，不用 tāi、yí、sì。

笛子的「子」读轻声。舞和蹈都用「舞蹈」。

## 改掉的候选

- H0850 弹：字表候选是「导弹」，不适合儿童。改用「弹琴」，读 tán qín。
- H0853 打：字表候选是「打击」，不适合儿童。改用「打鼓」，读 dǎ gǔ。
- H0860 弓：字表候选是「弓箭」，不适合儿童。改用「琴弓」，读 qín gōng。

琴弓画在小提琴旁边，不是弓箭。锣和鼓面上没有字。风筝是纯色的。钢琴上没有乐谱。
