# 第二十一批识字卡：第021组「身体与健康」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0400 的单卡、已有打印页、PDF，以及第001组到第020组的说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：021
- 主题：身体与健康
- 卡号：H0401–H0420

字表没有定稿例句。例句按第001组的难度起草，例词用字表候选。

多音字按例词取音：

- 眼：眼睛，取 yǎn，不用 wěn。
- 睛：眼睛，取 jīng，不用 jǐng。眼睛的「睛」读轻声。
- 唇：嘴唇，取 chún，不用 zhēn、zhèn。
- 舌：舌头，取 shé，不用 guā。舌头的「头」读轻声。
- 脖：脖子，取 bó，不用 bō。脖子的「子」读轻声。
- 肩：肩头，取 jiān，不用 xián。
- 背：背景，取 bèi，不用 bēi。若要「背东西」的 bēi，例词不能再用「背景」。
- 肚：鱼肚，取 dù，不用 dǔ。若要「肚子」的 dǔ，例词不能再用「鱼肚」。
- 脚：脚步，取 jiǎo，不用 jué。
- 指：指出，取 zhǐ，不用 zhī、zhí。
- 臂：手臂，取 bì，不用轻声 bei。

脸上的「上」、肠子的「子」读轻声。
