# 第四十二批识字卡：第042组「运动与比赛」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0820 的单卡、已有打印页、PDF，以及第001组到第041组的说明都没有改。H0485 也没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。笔画很多时，田字格会略缩小，使每一笔都留在卡片里面。赢有 17 笔，操有 16 笔，格子都收在卡片里。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：042
- 主题：运动与比赛
- 卡号：H0821–H0840

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选明显不适合儿童时，改用同一个字的生活词。

多音字按例词取音：

- 运：运动，取 yùn，不用 yǔn。
- 活：生活，取 huó，不用 guō。
- 体：身体，取 tǐ，不用 tī、bèn、cuì。
- 育：教育，取 yù，不用 zhòu、yō。
- 胜：胜利，取 shèng，不用 xīng、qìng、shēng。
- 冠：冠军，取 guàn，不用 guān。若要「衣冠」的 guān，例词不能再用「冠军」。
- 滑：下滑，取 huá，不用 gǔ。
- 溜：一溜，取 liù，不用 liū、liú。一读 yí。若要「溜冰」的 liū，例词不能再用「一溜」。

## 改掉的候选

- H0825 体：字表候选是「政体」，不适合儿童。改用「身体」，读 shēn tǐ。

失败画的是坐在草地上，没有受伤。奖励的奖杯是空白的。冠军的金牌上没有字。卡车运输没有车牌。
