# 第六十一批识字卡：第061组「口、囗、土部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1200 的单卡、已有打印页、PDF，以及第001组到第060组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：061
- 主题：口、囗、土部字形联系
- 卡号：H1201–H1220

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。

多音字按例词取音：

- 唯：唯一，取 wéi，不用 wěi。
- 喊：大喊，取 hǎn，不用 kàn、jiān。
- 困：困难，取 kùn。难读轻声 nan。
- 圣：圣诞树，取 shèng，不用 kū。
- 均：平均，取 jūn，不用 yùn。
- 垂：垂下，取 chuí，不用 zhuì。
- 埃：埃及，取 āi，不用 zhì。
- 埋：埋种子，取 mái，不用 mán。子读轻声 zi。

善、嘉、因、围、固、在、址、坛、坦、型、基、域在这一组的例词里只有一个读音，分别是 shàn、jiā、yīn、wéi、gù、zài、zhǐ、tán、tǎn、xíng、jī、yù。

## 改掉的候选

- H1202 善：字表候选是「完善」，偏书面。改用「善良」，读 shàn liáng。
- H1203 喊：字表候选是「呐喊」，偏书面。改用「大喊」，读 dà hǎn。
- H1204 嘉：字表候选是「嘉靖」，是年号。改用「姓嘉」，读 xìng jiā。
- H1206 围：字表候选是「范围」，偏抽象。改用「围巾」，读 wéi jīn。
- H1209 圣：字表候选是「圣地」，偏成人。改用「圣诞树」，读 shèng dàn shù。
- H1212 址：字表候选是「遗址」，生僻书面。改用「地址」，读 dì zhǐ。
- H1213 坛：字表候选是「论坛」，不适合儿童。改用「花坛」，读 huā tán。
- H1214 坦：字表候选是「坦克」，是武器。改用「平坦」，读 píng tǎn。
- H1215 垂：字表候选是「垂直」，偏书面。改用「垂下」，读 chuí xià。
- H1217 埃：字表候选是「尘埃」，生僻书面。改用「埃及」，读 āi jí。
- H1218 埋：字表候选是「埋伏」，不适合儿童。改用「埋种子」，读 mái zhǒng zi。
- H1220 域：字表候选是「领域」，偏抽象。改用「区域」，读 qū yù。
