# 第二批识字卡：第002组「家人与伙伴」

从这一组起用新版式。第001组 H0001–H0020 和 G001 打印页、PDF 没有改。

例词沿用字表里前 300 字的人工候选。例句和插画是按第001组的难度和生活场景起草的，还没有逐句请你定稿。

## 新版式（后面的组沿用）

1. 笔顺每一笔写在红色方格里。每一步一个红色方格，笔画画在格内。已经写过的笔画是深灰色，当前这一笔用橙红色。
2. 右侧组词用粗体，并且比第一批更大。
3. 例句放在插画正下方，用粗体，并且比第一批更大。

其余不变：顶栏是组名和卡号，左侧拼音和田字格大字，右侧还有词语拼音和水彩插画。5 寸横卡 1500×1050。A4 横向 2×2，卡外有裁切标记。笔画数和笔顺与字表里的规范笔顺编码一致。

## 起草的地方，可以改

这组可以先用。如果要改口吻，下面几处最值得看：

- 「父亲」「母亲」「子女」是字表里的候选词，比「爸爸」「妈妈」「孩子」更书面。爸、妈两张已经用了爸爸、妈妈，所以父、母、子换了这三个词，避免四张卡说同一句话。想改成更口语的词可以说。
- 「男孩在跑步」和「哥哥在跑步」都是跑步。男孩那张是一个男孩自己在跑，哥哥那张是哥哥跑、弟弟在旁边看。
- 「姐姐坐着看书」的书上没有字，画面上是纸页背面。
