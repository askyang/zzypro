# 第十二批识字卡：第012组「游戏与动作」

版式与第002组相同：笔顺写在红色方格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的卡片、打印页、PDF 和说明都没有改。

例词用字表候选。例句按生活场景起草，可以改。

## 这一组

- 阶段：生活启蒙
- 组号：012
- 主题：游戏与动作
- 卡号：H0221–H0240

多音字按例词取音：

- 拍：拍手，取 pāi，不用 bó。
- 跳：跳绳，取 tiào，不用 diào、táo。
- 踢：踢球，取 tī，不用 dié。
- 抱：拥抱，取 bào，不用 pāo、pǒu。
- 放：放下，取 fàng，不用 fǎng、fāng。
- 拉：拉手，取 lā，不用 lá、lǎ、là。
- 吹：吹气，取 chuī，不用 chuì。
- 读：读书，取 dú，不用 dòu。
- 写：写字，取 xiě，不用 xiè。
- 找：找到，取 zhǎo，不用 huá。
