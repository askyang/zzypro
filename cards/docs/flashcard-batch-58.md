# 第五十八批识字卡：第058组「刀、力、十等部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1140 的单卡、已有打印页、PDF，以及第001组到第057组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：058
- 主题：刀、力、十等部字形联系
- 卡号：H1141–H1160

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。

多音字按例词取音：

- 副：一副，取 fù，不用 pì。一在第四声前读 yí，所以是 yí fù。
- 务：任务，取 wù。务读轻声 wu。
- 劲：使劲，取 jìn，不用 jìng。
- 勒：勒紧，取 lēi，不用 lè、lei。
- 华：华丽，取 huá，不用 huà、huā。
- 单：单独，取 dān，不用 chán、shàn。
- 卒：仓卒，取 cù，不用 zú、cuì。字表字头写的是 zú，例词「仓卒」不取这个音。仓卒就是匆忙。
- 占：占座，取 zhàn，不用 zhān、tiē。

剩、办、劝、加、功、劳、势、勇、升、协、博、卢在这一组的例词里只有一个读音，分别是 shèng、bàn、quàn、jiā、gōng、láo、shì、yǒng、shēng、xié、bó、lú。

## 改掉的候选

- H1152 勒：字表候选是「勒令」，不适合儿童。改用「勒紧」，读 lēi jǐn。勒令读 lè，这张不取。
- H1154 华：字表候选是「华表」，生僻。改用「华丽」，读 huá lì。
- H1155 协：字表候选是「协议」，偏书面。改用「协助」，读 xié zhù。
- H1156 单：字表候选是「单位」，偏书面。改用「单独」，读 dān dú。
- H1157 卒：字表候选是「狱卒」，不适合儿童。改用「仓卒」，读 cāng cù。仓卒就是匆忙。
- H1158 博：字表候选是「博士」，偏成人。改用「博物馆」，读 bó wù guǎn。
- H1159 占：字表候选是「占领」，不适合儿童。改用「占座」，读 zhàn zuò。
- H1160 卢：字表候选是「卢主事」，不适合儿童。改用「姓卢」，读 xìng lú。
