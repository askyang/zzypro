# 第二十四批识字卡：第024组「厨房与烹饪」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0460 的单卡、已有打印页、PDF，以及第001组到第023组的说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：024
- 主题：厨房与烹饪
- 卡号：H0461–H0480

字表没有定稿例句。例句按第001组的难度起草，例词用字表候选。

多音字按例词取音：

- 炸：爆炸，取 zhà，不用 zhá。若要「油炸」的 zhá，例词不能再用「爆炸」。
- 煎：煎熬，取 jiān，不用 jiàn、jiǎn。
- 切：一切，取 qiè，不用 qiē、qì。一切的「一」在第四声前读 yí。若要「切开」的 qiē，例词不能再用「一切」。
- 剥：剥削，取 bō，不用 bāo、pū。若要「剥皮」的 bāo，例词不能再用「剥削」。
- 拌：搅拌，取 bàn，不用 pān。
- 盛：盛产，取 shèng，不用 chéng。若要「盛饭」的 chéng，例词不能再用「盛产」。

炉子的「子」、筷子的「子」读轻声。
