# 第八十七批识字卡：第087组「糸、缶、网部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1720 的单卡、已有打印页、PDF，以及第001组到第086组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难、矛盾都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：087
- 主题：糸、缶、网部字形联系
- 卡号：H1721–H1740

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。实在没有生活词，才用姓氏。

多音字按例词取音：

- 绕：绕圈，取 rào，不用 rǎo。
- 综：姓综，取 zōng，不用 zèng。
- 累：累了，取 lèi，不用 léi、lěi、lǜ、liè。了读轻声 le。
- 绩：成绩，取 jì，不用 jī。
- 繁：繁星，取 fán，不用 pó、pán。
- 缺：缺口，取 quē，不用 kuǐ。
- 罗：姓罗，取 luó，不用 luō。
- 罢：罢了，取 bà。了读轻声 le。不用 ba。

继、维、续、绪、编、缓、缘、网、罚、置、罪、署在这一组的例词里只有一个读音，分别是 jì、wéi、xù、xù、biān、huǎn、yuán、wǎng、fá、zhì、zuì、shǔ。继和续的例词都是「继续」，读 jì xù。

## 改掉的候选

- H1721 绕：字表候选是「围绕」，偏抽象。改用「绕圈」，读 rào quān。
- H1723 维：字表候选是「维护」，偏成人。改用「维生素」，读 wéi shēng sù。画面是切开的橙子。

- H1732 繁：字表候选是「繁殖」，不适合儿童。改用「繁星」，读 fán xīng。
- H1733 缺：字表候选是「缺乏」，偏抽象。改用「缺口」，读 quē kǒu。
- H1734 网：字表候选是「网络」，偏成人。改用「球网」，读 qiú wǎng。
- H1735 罗：字表候选是「喽罗」，不适合儿童。同字没有儿童生活词，改用「姓罗」，读 xìng luó。
- H1736 罚：字表候选是「处罚」，不适合儿童。同字没有儿童生活词，改用「姓罚」，读 xìng fá。
- H1737 罢：字表候选是「罢工」，靠近劳役。改用「罢了」，读 bà le。
- H1739 罪：字表候选是「犯罪」，不适合儿童。同字没有儿童生活词，改用「姓罪」，读 xìng zuì。
- H1740 署：字表候选是「部署」，靠近军事。同字没有儿童生活词，改用「姓署」，读 xìng shǔ。
