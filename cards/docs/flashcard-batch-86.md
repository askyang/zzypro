# 第八十六批识字卡：第086组「米、糸部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1700 的单卡、已有打印页、PDF，以及第001组到第085组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难、矛盾都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：086
- 主题：米、糸部字形联系
- 卡号：H1701–H1720

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。实在没有生活词，才用姓氏。

多音字按例词取音：

- 精：精彩，取 jīng，不用 qíng、jìng。
- 约：约好，取 yuē，不用 yāo。
- 纤：纤细，取 xiān，不用 qiàn。
- 系：系鞋带，取 jì，不用 xì。
- 结：打结，取 jié，不用 jiē。
- 络：网络，取 luò，不用 lào。

类、粒、级、纳、纵、纯、纺、纷、纲、组、练、绍、统、绝在这一组的例词里只有一个读音，分别是 lèi、lì、jí、nà、zòng、chún、fǎng、fēn、gāng、zǔ、liàn、shào、tǒng、jué。

## 改掉的候选

- H1702 粒：字表候选是「粒子」，偏物理。改用「米粒」，读 mǐ lì。
- H1703 精：字表候选是「精神」，偏抽象。改用「精彩」，读 jīng cǎi。
- H1704 级：字表候选是「各级」，偏行政。改用「年级」，读 nián jí。
- H1705 约：字表候选是「条约」，偏成人。改用「约好」，读 yuē hǎo。
- H1706 纤：字表候选是「纤维」，偏工业。改用「纤细」，读 xiān xì。
- H1707 系：字表候选是「关系」，偏抽象。改用「系鞋带」，读 jì xié dài。
- H1708 纳：字表候选是「纳入」，偏成人。改用「收纳」，读 shōu nà。
- H1709 纵：字表候选是「操纵」，不适合儿童。同字没有儿童生活词，改用「姓纵」，读 xìng zòng。
- H1710 纯：字表候选是「单纯」，偏抽象。改用「纯白」，读 chún bái。
- H1711 纺：字表候选是「纺织」，偏产业。改用「纺线」，读 fǎng xiàn。
- H1713 纲：字表候选是「纲领」，偏成人。同字没有儿童生活词，改用「姓纲」，读 xìng gāng。
- H1714 组：字表候选是「组织」，偏成人。改用「小组」，读 xiǎo zǔ。
- H1715 练：字表候选是「训练」，容易像操练。改用「练习」，读 liàn xí。
- H1717 统：字表候选是「系统」，偏成人。改用「统统」，读 tǒng tǒng。
- H1718 结：字表候选是「结构」，偏抽象。改用「打结」，读 dǎ jié。
