# 第八十三批识字卡：第083组「疋、疒、癶等部字形联系」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H1640 的单卡、已有打印页、PDF，以及第001组到第082组的说明都没有改。H0485、H0981「的」、H0982「了」、H1084「侵晨」、H1157「仓卒」、围堰、古墓、媒体、宪法、匈奴、尸体、皇帝、宫廷、劳役、忧患、宗旨、名曰、腹部、欲望、档案、灾难都留着，等用户决定。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：083
- 主题：疋、疒、癶等部字形联系
- 卡号：H1641–H1660

字表没有定稿例句。例句按第001组的难度起草。例词优先用字表候选。候选不适合儿童，或生僻书面、孩子听不懂时，改用同一个字的生活词。

多音字按例词取音：

- 疑：怀疑，取 yí，不用 níng。
- 症：姓症，取 zhèng，不用 zhēng。
- 痛：痛了，取 tòng。了读轻声 le。
- 登：登山，取 dēng，不用 dé。
- 皇：皇帝，取 huáng，不用 wǎng。
- 监：姓监，取 jiān，不用 jiàn。
- 盖：盖子，取 gài，不用 gě。子读轻声 zi。
- 盟：姓盟，取 méng，不用 mèng、míng。
- 省：省钱，取 shěng，不用 xǐng、xiǎn。
- 盾：矛盾，取 dùn，不用 shǔn、yǔn。
- 瞧：瞧瞧，读 qiáo qiao。后一个瞧读轻声。

疏、疗、病、疾、皆、皮、益、盗、督在这一组的例词里只有一个读音，分别是 shū、liáo、bìng、jí、jiē、pí、yì、dào、dū。

## 改掉的候选

- H1641 疏：字表候选是「奏疏」，偏成人公文。改用「稀疏」，读 xī shū。
- H1644 病：字表候选是「疾病」，是疾病名。改用「毛病」，读 máo bìng。画面是袜子上的小洞。
- H1645 疾：字表候选是「疾病」，是疾病名。改用「疾风」，读 jí fēng。
- H1646 症：字表候选是「症状」，是疾病用语。同字没有儿童生活词，改用「姓症」，读 xìng zhèng。
- H1647 痛：字表候选是「痛苦」，偏成人。改用「痛了」，读 tòng le。纱布上没有红十字。
- H1648 登：字表候选是「登时」，偏书面。改用「登山」，读 dēng shān。
- H1650 皆：字表候选是「皆知」，偏书面。同字没有更浅的生活词，改用「姓皆」，读 xìng jiē。
- H1652 监：字表候选是「监督」，偏成人。同字没有儿童生活词，改用「姓监」，读 xìng jiān。
- H1653 益：字表候选是「利益」，偏成人。改用「益虫」，读 yì chóng。
- H1654 盖：字表候选是「覆盖」，偏书面。改用「盖子」，读 gài zi。
- H1655 盗：字表候选是「强盗」，不适合儿童。同字没有儿童生活词，改用「姓盗」，读 xìng dào。手里没有东西。
- H1656 盟：字表候选是「盟主」，偏成人。同字没有儿童生活词，改用「姓盟」，读 xìng méng。
- H1657 省：字表候选是「全省」，偏行政区划。改用「省钱」，读 shěng qián。罐子和硬币上都没有字。
- H1659 督：字表候选是「监督」，偏成人。同字没有儿童生活词，改用「姓督」，读 xìng dū。
