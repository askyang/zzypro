# 第十八批识字卡：第018组「交流与提问」

版式与第014组、第016组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。H0001–H0340 的单卡、已有打印页、PDF，以及第001组到第017组的说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，已写笔画深灰，当前笔橙红。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙留白，没有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进缝隙。这一组的五张打印页沿用这一版。

## 这一组

- 阶段：日常扩展
- 组号：018
- 主题：交流与提问
- 卡号：H0341–H0360

字表没有定稿例句。例句按第001组的难度起草，例词用字表候选。

多音字按例词取音：

- 答：回答，取 dá，不用 dā。
- 告：报告，取 gào，不用 jū、gù。
- 聊：无聊，取 liáo，不用 liú。
- 论：理论，取 lùn，不用 lún。
- 知：知道，取 zhī，不用 zhì。
- 思：思想，取 sī，不用 sāi。
- 忘：忘记，取 wàng，不用 wáng。
- 谜：谜底，取 mí，不用 mèi。
- 为：字表参考音是 wèi。例词「成为」读 wéi，卡上写 wéi。若要 wèi，例词不能再用「成为」。
- 什：什么，取 shén，不用 shí。

告诉的「诉」、懂得的「得」、什么的「么」读轻声。认为的「为」也读 wéi。
