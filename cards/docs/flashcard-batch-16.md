# 第十六批识字卡：第016组「在学校学习」

版式与第014组相同：笔顺写在红色田字格里，组词粗体放大，例句在插画正下方并粗体放大。前面各组的单卡、打印页、PDF 和说明都没有改。

红色田字格从 H0261 起。这一组同样使用：红色外框，红色虚线中心十字，和左侧大字的田字格是同一套。

## A4 缝隙

从 **第016组** 的 A4 页起，四张卡之间的缝隙不再有黑色细线。裁切标记只留在纸张外缘，朝外，不伸进卡与卡的缝隙。第015组及更早的打印页已经落盘，缝隙里的黑细线保持原样。

## 这一组

- 阶段：日常扩展
- 组号：016
- 主题：在学校学习
- 卡号：H0301–H0320

多音字按例词取音：

- 教：教育，取 jiào，不用 jiāo。
- 本：基本，取 běn，不用 bēn。
- 句：一句，取 jù，不用 gōu、gòu、qú。词里的「一」在第四声前读 yí。
- 语：语言，取 yǔ，不用 yù。
- 数：人数，取 shù，不用 shǔ、shuò。
- 英：精英，取 yīng，不用 yāng。
- 术：技术，取 shù，不用 zhú、shú。

学生的「生」、师父的「父」、名字的「字」读轻声。
