# 中国地形 · 交互式 3D 沙盘

基于 **Three.js + Vite** 的中文交互式三维地形沙盘。仓库本身没有现成 DEM/地形图文件，因此内置了**程序化中国高程模型**（示意三大阶梯与主要地貌区），可本地流畅运行。

## 功能

1. **交互**：拖拽旋转；鼠标滚轮 / 触控捏合缩放（OrbitControls）。
2. **脉冲点**：塔里木盆地、青藏高原、内蒙古高原、华北平原、东北平原、喜马拉雅山脉、云贵高原、四川盆地。点击飞入并展示说明，可语音播报。
3. **地图模式**：`阶梯着色` / `等高线` 一键切换。
4. **地形夸张度**：滑杆控制起伏强度。
5. **自动巡礼**：自喜马拉雅山脉起依次飞入各脉冲点，并语音解说。
6. **语音**：Web Speech API（`zh-CN`）；侧栏「语音播放」可播/停；未播放时简介栏可点击播报。
7. **北纬 36° 剖面**：自西向东展示三大阶梯剖面图。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

## 技术说明

| 模块 | 说明 |
|------|------|
| `src/terrain/heightmap.js` | 程序化高程与陆地掩膜 |
| `src/terrain/materials.js` | 阶梯着色 / 等高线 Shader |
| `src/terrain/markers.js` | 脉冲点与标签 |
| `src/data/regions.js` | 区域经纬度与解说文案 |
| `src/ui/speech.js` | 语音播放封装 |
| `src/ui/profile.js` | 北纬 36° 剖面绘制 |

## 已知限制

- 高程为**教学示意模型**，非实测 DEM，海拔与形态为近似。
- 语音依赖浏览器 Web Speech API；部分环境（无中文语音包、无用户手势）可能无法出声。
- 中国国界轮廓为粗略多边形掩膜，仅作沙盘示意。

## 许可

演示项目；高程为合成数据，不用于测绘或工程用途。
